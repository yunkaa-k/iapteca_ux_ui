## Представление данных

- Заполнены действующие вещества, содержание в единице лекарственной формы, форма, упаковка, производитель, страна, возрастные/весовые ограничения и АТХ.
- `dosageForm` остаётся кодом для фильтрации; необязательное `dosageFormDetails` содержит точную форму из инструкции, например покрытые оболочкой таблетки.
- Необязательное `packageDescription` описывает упаковку. Для мази это одна туба 30 г; `packSize` не превращается в 30 единиц, цена за таблетку не вычисляется.
- Возрастные ограничения не выводятся из названия: у Нурофена 200 мг, Форте, ибупрофена 400 мг и других препаратов сохранены собственные условия. Для амоксициллина не выдумывается единый возрастной порог: форма и дозирование детям выбираются по инструкции и назначению врача.
- Краткие сведения не содержат схем лечения. Полная инструкция открывается отдельной ссылкой.

## Заполнение локальной базы

Предпросмотр: `node scripts/fill-local-catalog-facts.mjs`.

Применение: `node scripts/fill-local-catalog-facts.mjs --apply`.

Скрипт допускает только loopback MongoDB `iapteca`, Replica Set `rs0` с PRIMARY. Проверяет 11 детерминированных ID и заполняет только пустые характеристики или значения `Не вказано`. При конфликте с непустым значением останавливается. Перед изменениями сохраняет копию в игнорируемой `.local/backups/`. Обновление атомарно; все остальные поля сравниваются с исходными документами до commit. Пользователи, заказы и аптечки не записываются.

Применение выполнено: заполнены 11 препаратов. Повторный запуск: 0 изменений. Цены, остатки, категории, изображения, флаги рецептурности и ID сохранены. Для новой базы `seed-local-catalog.mjs` использует этот же справочник при вставке; существующие товары seed не перезаписывает.
